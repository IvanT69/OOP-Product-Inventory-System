## Introduction 
The Product Inventory Management System is a console-based Java application that is designed to help efficiently track, organize and maintain records of product stock. 
## System Objectives
- To allow users to add, search, view, and delete product records. (CRUD)
- To reduce errors caused by manual inventory record-keeping.
- To demonstrate the use of object-oriented programming principles. 
- To apply arrays of objects, methods, file handling, input validation, and exception handling.
- To provide a simple and user-friendly console-based menu.
